# Ascend original soundtrack

These 30 instrumental cues were composed and synthesized specifically for this
project by `scripts/generate-music.mjs`. They contain no samples, recordings, or
third-party music assets.

The checked-in `.m4a` files are the compressed runtime masters. The generator
creates uncompressed `.wav` sources in `.music-source/` by default so the
compositions can be regenerated and re-encoded without degrading the masters.

The soundtrack covers onboarding, four class home themes, four skill-tree
themes, party and profile spaces, the raid hall, six dungeons, four class battle
themes, six bosses, victory, and defeat.
